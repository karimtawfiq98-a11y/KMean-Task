K-Means Clustering – Computer Vision Task

Project Description

This project implements the K-Means Clustering algorithm using Python to group hypothetical data points into three clusters based on their similarity.

Technologies Used

* Python
* NumPy
* Matplotlib
* Scikit-learn

Dataset

The project uses hypothetical 2D points, where each point has X and Y coordinates.

Algorithm Steps

1. Create hypothetical data points.
2. Set the number of clusters (K = 3).
3. Apply the K-Means algorithm.
4. Assign each point to its nearest cluster.
5. Calculate the cluster centers (Centroids).
6. Visualize the results using Matplotlib.

Results

The algorithm successfully divides the points into three clusters and displays their centroids using red X markers.

How to Run

Install the required libraries:

pip install numpy matplotlib scikit-learn

Run the project:

python main.py
